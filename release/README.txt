=======================================================
3D SHOP SIMULATOR - FINAL RELEASE
=======================================================

Instruksi Menjalankan Game:
1. Jalankan `ShopSimulator.exe`.
2. Folder `assets` dan `save` berada di direktori yang sama dengan executable.

Kontrol Keyboard & Mouse:
- W / A / S / D     : Bergerak
- Mouse             : Mengarahkan kamera pandangan (First-Person)
- E                 : Interaksi (Ambil/Taruh produk di Rak & Storage)
- M / ESC           : Menu Utama & Save / Load Game
- F5 / F9           : Quick Save / Quick Load
- TAB               : Menu Pengadaan Barang (Supplier & Order)
- P                 : Manajemen Harga Jual Produk
- F                 : Ringkasan Finansial & Profit/Loss
- R                 : Evaluasi Reputasi & Rating Toko
- U                 : Upgrade Toko (Shop Upgrade)
- B                 : Katalog Furniture & Peralatan Tambahan
- SPACE / ENTER     : Buka Hari Berikutnya (saat Toko Tutup)

Fitur Utama:
- First-person 3D Shop Environment dengan 60 FPS Native C++ raylib
- Dynamic Audio Synthesizer (Sistem suara procedural fallback-safe)
- Siklus Waktu Harian (08:00 - 21:00) & Daily Summary Operasional
- Sistem Rating Kepuasan Pelanggan (1-5 Bintang) & Reputasi Dinamis
- Manajemen Ekonomi Toko (Modal, Margin, Restock, Biaya Operasional)
- Save / Load System Slot 1-3 & Autosave Harian

Selamat bermain!
